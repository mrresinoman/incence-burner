# MR RESIN — حاسبة حديد المباخر

موقع عربي متجاوب يعمل مباشرة على GitHub Pages، دون خادم أو قواعد بيانات.

## النشر
1. أنشئ مستودع GitHub جديدًا (مثل `mr-resin-calculator`).
2. ارفع ملف `index.html` إلى جذر المستودع.
3. لإظهار **الشعار الأصلي**، أضف صورة شعار MR RESIN الأصلية باسم `logo.png` إلى جذر المستودع. إذا لم تضفها سيظهر شعار نصي مؤقت بألوان المتجر.
4. من Settings → Pages → Build and deployment اختر Deploy from a branch ثم `main` و`/(root)` واضغط Save.
5. افتح الرابط الذي سيظهر في إعدادات Pages.

## الأسعار
الأسعار في كائن `prices` داخل `index.html` **بالبيسة لكل قطعة**. عدّل القيم هناك عند تغيير الأسعار.

## التقريب
يجري حساب الأسعار بدقة البيسة ثم تقريب إجمالي الطلب مرة واحدة إلى أقرب 100 بيسة، مع تقريب 50 بيسة للأعلى. لا تشمل الأسعار رسوم التوصيل.
